# copper-cloud v0.3.0

Canvas sharing is now ready for Copper clients. Members can create opaque editor share links,
owners can list and reset them, and signed-in recipients can preview and join a canvas. Joins are
safe to retry, preserve owner roles, remove matching pending email invites, count uses, and emit
the normal canvas membership SSE event. Share-link secrets are SHA-256 hashed at rest and cascade
when a canvas is deleted.

This release also adds the authenticated `/v1/people` directory for active, searchable instance
members and an ungated `/join/{token}` HTML handoff page that safely opens a valid cloud host in
Copper without looking up or exposing canvas data. The admin canvas view reports the number of
active share links. Documentation and deployment examples now identify the 0.3.0 release.
